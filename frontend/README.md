# 🎨 Frontend - Interface de Gestion de Stock

Interface web moderne et réactive pour la gestion de stock informatique.

## 🚀 Démarrage rapide

### Option recommandée : VS Code Live Server
1. Installer l'extension "Live Server" dans VS Code
2. Ouvrir `index.html`
3. Clic droit → "Open with Live Server"

### Autres options
```bash
# Python
python -m http.server 8080

# Node.js
npx http-server -p 8080

# Directement
Double-cliquez sur index.html
```

## 📋 Prérequis

- Backend API démarré sur `http://localhost:3000`
- Base de données MySQL `gestion_stock` opérationnelle
- Navigateur moderne

## ✨ Fonctionnalités

- 📊 **Tableau de bord** : Statistiques en temps réel
- 🔍 **Gestion du stock** : Recherche et filtrage
- 🛒 **Vente rapide** : Interface optimisée pour les ventes
- 📜 **Historique** : Traçabilité complète des mouvements
